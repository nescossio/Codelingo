Introdução à Programação com Python

Curso introdutório completo voltado ao desenvolvimento do raciocínio lógico, compreensão dos fundamentos da programação e aplicação prática utilizando a linguagem Python.

Capítulo 1 – Fundamentos da Programação

Antes de aprender uma linguagem de programação específica, é fundamental compreender o que significa programar. Programar consiste em elaborar uma sequência lógica de instruções que será interpretada e executada por um computador. Essas instruções precisam ser claras, organizadas e escritas de forma que a máquina consiga compreendê-las.

Um programa de computador nada mais é do que a formalização de uma solução para um problema. Essa solução deve ser descrita passo a passo, considerando todas as situações possíveis. Esse processo desenvolve o chamado raciocínio lógico, habilidade essencial para qualquer profissional da área de tecnologia.

A linguagem Python foi criada com o propósito de facilitar esse processo. Ela prioriza a legibilidade do código e reduz a quantidade de símbolos complexos, tornando o aprendizado mais acessível para iniciantes, sem abrir mão de poder e flexibilidade.

Python é atualmente utilizada em diversas áreas, como desenvolvimento de sistemas, aplicações web, automação de tarefas, ciência de dados, inteligência artificial e computação científica. 


print("Olá, mundo!")

O comando acima utiliza a função print(), responsável por exibir informações na tela. Tradicionalmente, esse é o primeiro programa escrito por quem está iniciando em programação.

Capítulo 2 – Variáveis, Memória e Tipos de Dados

Para que um programa possa armazenar e manipular informações, é necessário utilizar variáveis. Uma variável pode ser entendida como um espaço reservado na memória do computador, onde um valor é armazenado temporariamente durante a execução do programa.

Cada variável possui um nome, que será utilizado para acessar o valor armazenado. Esse nome deve ser escolhido de forma clara e representativa, facilitando a leitura e a manutenção do código.

Em Python, o tipo da variável não precisa ser declarado previamente. O interpretador identifica automaticamente o tipo do dado no momento da atribuição.

Tipos numéricos

Os tipos numéricos são utilizados para representar valores quantitativos. Os dois principais tipos numéricos básicos em Python são os inteiros (int) e os números decimais (float). 


quantidade = 15      # inteiro
preco = 19.90        # decimal

Valores inteiros são utilizados quando não há necessidade de casas decimais, enquanto os valores do tipo float são empregados em cálculos mais precisos.

Tipo texto (strings)

Strings são sequências de caracteres utilizadas para representar textos. Elas são fundamentais para trabalhar com nomes, mensagens, descrições e qualquer informação textual. 


nome = "João"
mensagem = "Bem-vindo ao curso de Python"

Strings podem ser delimitadas por aspas simples ou duplas, desde que o padrão seja mantido corretamente.

Tipo lógico (booleano)

O tipo booleano representa valores lógicos, ou seja, verdadeiro ou falso. Esses valores são amplamente utilizados em estruturas de decisão e controle de fluxo. 


ativo = True
finalizado = False

Entrada de dados pelo usuário

Programas interativos frequentemente necessitam receber informações do usuário. Em Python, isso é feito por meio da função input(). 


nome = input("Digite seu nome: ")
idade = int(input("Digite sua idade: "))

É importante destacar que todo dado recebido por input() é tratado inicialmente como texto. Por isso, quando se espera um número, é necessário realizar a conversão para o tipo adequado.

Capítulo 3 – Strings e Processamento de Texto

O processamento de texto é uma das tarefas mais comuns em programação. Python oferece uma grande variedade de recursos para trabalhar com strings de forma eficiente e intuitiva.

Uma string é uma sequência ordenada de caracteres, e cada caractere possui uma posição, também chamada de índice. O primeiro caractere sempre possui índice zero. 


texto = "Programação em Python"

Operações básicas com strings

Python disponibiliza diversos métodos prontos para manipular strings. Esses métodos facilitam tarefas como conversão de letras, verificação de conteúdo e contagem de caracteres. 


len(texto)                 # retorna o tamanho do texto
texto.upper()              # converte para maiúsculas
texto.lower()              # converte para minúsculas
texto.capitalize()         # primeira letra maiúscula
texto.count("o")           # conta ocorrências
texto.startswith("Pro")    # verifica início
texto.endswith("thon")     # verifica final

Fatiamento de strings

O fatiamento permite extrair partes específicas de uma string, utilizando intervalos definidos por índices. Essa técnica é muito útil para análise e manipulação de textos. 


palavra = "Python"

palavra[0:3]   # 'Pyt'
palavra[2:]    # 'thon'
palavra[:4]    # 'Pyth'

Capítulo 4 – Operadores e Expressões

Operadores são símbolos utilizados para realizar cálculos, comparações e avaliações lógicas. Eles são fundamentais para a construção de expressões que determinam o comportamento de um programa.

Operadores aritméticos


a = 10
b = 3

a + b   # soma
a - b   # subtração
a * b   # multiplicação
a / b   # divisão
a % b   # resto
a ** b  # potência

Operadores de comparação e lógicos


idade = 20
tem_autorizacao = True

if idade >= 18 and tem_autorizacao:
    print("Acesso permitido")

Esses operadores permitem que o programa tome decisões com base em condições.

Capítulo 5 – Estruturas de Decisão (Condicionais)

Em programação, muitas situações exigem que o programa tome decisões diferentes dependendo dos dados que estão sendo processados. Essas decisões são baseadas em condições lógicas, que podem ser verdadeiras ou falsas.

As estruturas de decisão permitem alterar o fluxo normal de execução de um programa. Em vez de executar todas as instruções de forma sequencial, o programa pode escolher qual bloco de código será executado.

Em Python, as principais estruturas de decisão são: if, if...else e if...elif...else.

Estrutura condicional simples (if)

A estrutura if é utilizada quando se deseja executar um bloco de código apenas se uma determinada condição for verdadeira. 


idade = 18

if idade >= 18:
    print("Usuário maior de idade")

Se a condição for falsa, o bloco interno simplesmente não é executado.

Estrutura condicional composta (if / else)

Quando é necessário definir um comportamento alternativo para o caso da condição não ser satisfeita, utiliza-se a estrutura else. 


idade = 16

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")

Estrutura condicional encadeada (if / elif / else)

Em situações onde existem várias possibilidades, utiliza-se o comando elif. O Python avalia as condições na ordem em que aparecem, executando apenas o primeiro bloco verdadeiro. 


nota = 5.5

if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")

Essa estrutura é amplamente utilizada em sistemas de avaliação, menus e validações.

Capítulo 6 – Estruturas de Repetição (Laços)

Estruturas de repetição são utilizadas quando se deseja executar um mesmo conjunto de instruções várias vezes. Essas estruturas são fundamentais para evitar repetição manual de código e tornar os programas mais eficientes.

Em Python, os principais laços de repetição são o while e o for.

Laço while

O laço while executa um bloco de código enquanto uma condição lógica for verdadeira. A condição é verificada antes de cada repetição. 


contador = 0

while contador < 5:
    print("Valor:", contador)
    contador += 1

É fundamental garantir que a condição eventualmente se torne falsa, evitando laços infinitos.

Laço for

O laço for é utilizado quando se conhece previamente a quantidade de iterações ou quando se deseja percorrer uma sequência de valores. 


for i in range(1, 6):
    print("Número:", i)

O comando range() gera uma sequência de números inteiros, podendo receber valores de início, fim e passo.

Controle de laços

Os comandos break e continue permitem controlar o fluxo de execução dentro dos laços. 


for i in range(10):
    if i == 5:
        break
    print(i)


for i in range(5):
    if i == 2:
        continue
    print(i)

Capítulo 7 – Listas

Listas são estruturas de dados que permitem armazenar múltiplos valores em uma única variável. Elas são ordenadas, mutáveis e muito versáteis.

Cada elemento de uma lista possui um índice, iniciando sempre em zero. 


valores = [10, 20, 30, 40]
print(valores[0])

Manipulação de listas

Python oferece diversas funções e métodos para manipular listas. 


numeros = [5, 2, 9, 1]

numeros.append(7)
numeros.sort()
numeros.reverse()

Fatiamento de listas


numeros = [0, 1, 2, 3, 4, 5]
numeros[1:4]

Listas com range


lista = list(range(0, 20, 2))

Capítulo 8 – Tuplas

Tuplas são estruturas semelhantes às listas, porém imutáveis. Isso significa que seus elementos não podem ser alterados após a criação.

Elas são utilizadas quando se deseja garantir que um conjunto de dados não seja modificado acidentalmente. 


coordenadas = (10, 20)

Desempacotamento de tuplas


x, y = coordenadas
print(x, y)

Capítulo 9 – Dicionários

Dicionários são estruturas que armazenam dados no formato chave–valor, permitindo acesso rápido às informações por meio de uma chave. 


aluno = {
    "nome": "Lucas",
    "idade": 22,
    "curso": "ADS"
}

Manipulação de dicionários


aluno["idade"] = 23
aluno["matricula"] = "20250123"

Percorrendo dicionários


for chave, valor in aluno.items():
    print(chave, ":", valor)

Capítulo 10 – Funções

Funções permitem organizar o código em blocos reutilizáveis, facilitando a manutenção e a leitura dos programas.

Definição de função


def saudacao():
    print("Bem-vindo ao Codelingo")

Funções com parâmetros


def saudacao(nome):
    print("Olá,", nome)

Retorno de valores


def soma(a, b):
    return a + b

Escopo de variáveis

Variáveis definidas dentro de uma função possuem escopo local e não afetam variáveis externas com o mesmo nome. 


def exemplo():
    x = 10
    print(x)

x = 5
exemplo()
print(x)

Parâmetros com valor padrão


def calcular_desconto(valor, taxa=10):
    return valor * taxa / 100
